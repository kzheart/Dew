## 同步算法

```ts {2,4}
export function sync(src: Pane, view: Pane) {
  const map = buildBlockMap(src.doc);
  view.onScroll((y) => {
    src.scrollTo(map.toSource(y));
  });
}
```

## 模式对比

| 模式 | 适合场景 | 快捷键 |
| :-- | :-- | :-: |

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

[^1]: 以段落为锚点换算位置，而不是按总高度比例滚动。
